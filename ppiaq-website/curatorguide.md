# Curator Account Guide (Website User)

This guide is for people who use the curator account on the website.
It focuses only on daily usage: login, create event, edit event, delete event, and publish.

## 1. Curator Login

Use this account:

- Email: `curator@ppiaq.org`
- Password: `Curator123!`

Login steps:

1. Open: `https://ppiaqueensland.org/auth/login`
2. Enter curator email and password.
3. Click Sign In.
4. You will be redirected to the Curator Events page.

If login fails, contact the admin who manages website accounts.

## 2. What You Can Do as Curator

After login, go to **Curator Dashboard** at:

- `https://ppiaqueensland.org/curator/events`

Main features:

- View all events
- Filter events by status: All, Draft, Published
- Create a new event
- Edit an existing event
- Delete an event

## 3. Understanding Event Status

- **DRAFT**: Event is saved but not shown publicly.
- **PUBLISHED**: Event is visible on the public website.

Use **DRAFT** while preparing content, then switch to **PUBLISHED** when ready.

## 4. Create New Event

Open:

- `https://ppiaqueensland.org/curator/events/create`

Fill in the form:

### Basic Information (Required)
- **Day**: Date number for event card, for example `5`
- **Month**: Short month text, for example `FEB`
- **Title**: Fill both Indonesian and English tabs
- **Full Date**: Full readable date, for example `Thursday, February 5, 2026`
- **Location**: Fill both Indonesian and English tabs

### Details
- **Description**: Recommended, fill both Indonesian and English tabs
- **Registration URL**: Optional, use full link starting with `https://`

### Media
- Upload event image (recommended)
- Supported files: JPG, JPEG, PNG, WEBP
- Maximum size: 5MB

### Publish
- Choose **DRAFT** or **PUBLISHED**

Then click **Create Event**.

## 5. Edit Existing Event

1. Go to Curator Events page.
2. Find the event card you want to change.
3. Click **Edit Event**.
4. Update any fields needed.
5. Click **Update Event**.

You can also change status here (Draft to Published or Published to Draft).

## 6. Delete Event

1. Go to Curator Events page.
2. Find the event card.
3. Click **Delete Event**.
4. Confirm deletion in the popup.

Important:

- Deletion is permanent.
- Deleted events cannot be restored from the curator page.

## 7. Good Publishing Checklist

Before setting event to **PUBLISHED**, check:

- Title is complete in Indonesian and English
- Location is complete in Indonesian and English
- Full Date is clear and correct
- Event image is uploaded and looks good
- Registration URL works (if used)
- No spelling mistakes

## 8. Logout

To log out:

1. Click your account menu/header button.
2. Click **Logout**.

You will return to the login/public page.

## 9. Quick Troubleshooting

### I cannot login
- Re-check email and password.
- Make sure Caps Lock is off.
- If still blocked, ask admin to reset curator account.

### Image upload fails
- Check file type (JPG/JPEG/PNG/WEBP).
- Make sure file size is under 5MB.

### Event not showing on public website
- Ensure status is **PUBLISHED**.
- Refresh page and check again.
